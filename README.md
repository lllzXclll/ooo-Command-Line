# C Command-Line - ooo

> This is a project meant to practice and show the abilities in handling files in C

## Description

This tool is a simple command-line created with the programming language C.  
This command-line supports the following commands:

- `help`  
  **Shows available commands and their syntax**

- `clear`  
  **Clears the screen**

- `copy [source] [destination]`  
  **Copies the content from source into destination. If destination doesn't exist it creates it**

- `count [file]`  
  **Counts lines, words, and characters**

- `search [content]`  
  **Shows the lines which have the specified content**

- `cf [file] [content]`  
  **"Create file" - Creates a file with the wanted content. Can leave content empty**

- `cdir [dir]`  
  **"Create directory" - Creates the specified dir**

- `rf [file]`  
  **"Remove file" - Removes specified file**

- `rdir [dir]`  
  **"Remove directory" - Removes specified directory. Asks for confirmation if it has content inside**
